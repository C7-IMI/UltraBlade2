# ULTRABLADE 2

The working home for **UltraBlade 2**.

The first game — a modern remake of the 1996 future-sport classic _HyperBlade_, built with
Godot 4.7.2 — lives in [C7-IMI/UltraBlade](https://github.com/C7-IMI/UltraBlade).
This repository is the fresh workspace for the second project.

## Status

Repository initialized. Design, engine notes and implementation evidence will land in `docs/`
as the project takes shape.

## Repository conventions

- Committed text is UTF-8 with LF line endings (`.gitattributes` enforces this).
- Generated output — builds, captures, local reference material — stays out of git (`.gitignore`).
